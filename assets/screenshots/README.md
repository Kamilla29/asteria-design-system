# Screenshot set

The web screenshots in this folder correspond to the stable web model case.

The browser game model case was substantially redesigned after the earliest screenshots were captured, so obsolete game screenshots are intentionally not kept as portfolio evidence. Current executable model cases are the source of truth.

Recommended portfolio/demo views:

1. Web companion portal — Home
2. Web companion portal — Registration
3. Game — Main Menu
4. Game — Gameplay + contextual HUD
5. Game — Inventory with selected/equipped item
6. Game — Quest Log
7. Game — Dialog
8. Game — Settings / critical HUD example
9. Godot runtime — title/gameplay scene
10. Cross-runtime design-system trace

For new screenshots, use the currently executed browser model case or the Godot runtime at a desktop resolution such as 1440×900.
